Image Segmentation

1One-line definition

Image segmentation assigns a class label to every pixel of an image. Semantic segmentation labels pixels by class only; instance segmentation also separates individual objects of the same class.

2Pipeline diagram to draw: U-Net

3Interactive demo: semantic vs instance vs panoptic

4Step-by-step explanation

In simple words

  1. Classification says "this image has a sheep". Segmentation colours in exactly which pixels are sheep.
  2. The encoder shrinks the image step by step and learns what is in it.
  3. The decoder enlarges it back to full size so every pixel gets a label.
  4. Skip connections hand the decoder sharp edges that were lost while shrinking.
  5. For instance segmentation the model also finds each object first, then draws a mask inside its box.

Technical version

  1. FCN (Long, Shelhamer and Darrell, 2015) replaces fully connected layers with convolutions so the network outputs a class map for any input size, then up-samples it.
  2. U-Net: contracting path of 3×3 convs + ReLU and 2×2 max pooling (channels 64 → 1024); expanding path of 2×2 up-convolutions; encoder features cropped and concatenated at each level; final 1×1 conv gives class scores per pixel. It trains well from few images (biomedical).
  3. DeepLab uses atrous (dilated) convolutions to enlarge the receptive field without losing resolution.
  4. Mask R-CNN (He et al., 2017) adds a mask branch to Faster R-CNN: for each detected box it predicts a 28×28 binary mask, giving instance segmentation.
  5. Loss: pixel-wise cross-entropy, often with Dice loss for small structures. Metrics: pixel accuracy, IoU per class, mean IoU (mIoU), Dice coefficient.

5Key formulas

\[\textbf{Pixel-wise cross-entropy:}\quad L=-\frac{1}{HW}\sum_{p=1}^{HW}\sum_{k=1}^{K}y_{p,k}\log\hat y_{p,k}\] \[\textbf{IoU}=\frac{|A\cap B|}{|A\cup B|}\qquad\qquad \textbf{Dice}=\frac{2|A\cap B|}{|A|+|B|}\qquad\qquad \textbf{mIoU}=\frac1K\sum_{k=1}^{K}\text{IoU}_k\] \[\textbf{Up-convolution output size:}\quad O=(W-1)S-2P+F\]
SymbolMeaning
\(H,W\)Image height and width; HW is the number of pixels.
\(K\)Number of classes.
\(y_{p,k},\ \hat y_{p,k}\)True one-hot label and predicted probability of class k at pixel p.
\(A,\ B\)Predicted mask and ground-truth mask (sets of pixels).
\(F,S,P\)Filter size, stride and padding of the transposed convolution.

7Advantages, disadvantages, applications

Advantages

  • Pixel-level detail, far finer than boxes.
  • U-Net trains well from few annotated images.
  • Fully convolutional: any input size.

Disadvantages

  • Pixel-level labels are very costly to make.
  • Thin structures and object boundaries are hard.
  • High memory use for large images.

Applications

  • Medical imaging: tumours, organs, cells.
  • Self-driving cars: road, lane, pedestrian.
  • Satellite images: land use, flooding.
  • Photo editing: background removal.

9Exam corner

2 marksDifferentiate semantic and instance segmentation.

Semantic segmentation assigns a class to every pixel but does not separate objects of the same class. Instance segmentation detects each object separately and gives each its own mask, so two cars get two different masks.

2 marksWhy does U-Net use skip connections?

Down-sampling loses fine spatial detail. Skip connections copy high-resolution encoder feature maps to the matching decoder level, where they are concatenated, so the decoder can place boundaries precisely.

2 marksDefine IoU and Dice for segmentation.

IoU = |A ∩ B| / |A ∪ B| and Dice = 2|A ∩ B| / (|A| + |B|), where A is the predicted mask and B the true mask. Both are 1 for a perfect match and 0 for no overlap.

Object Detection

1One-line definition

Object detection finds every object in an image, drawing a bounding box around each and naming its class with a confidence score; it combines classification ("what") with localization ("where").

2Pipeline diagram to draw: two-stage vs one-stage

3Interactive demo: IoU with real numbers, and the YOLO grid

4Step-by-step explanation

In simple words

  1. The model must say what each object is and draw a tight box around it.
  2. Two-stage detectors first guess "regions that might hold something", then check each guess carefully.
  3. One-stage detectors split the image into a grid and let every cell guess boxes at once: much faster.
  4. Many overlapping boxes appear for the same object; non-maximum suppression keeps the best one.
  5. We judge a box by how much it overlaps the true box (IoU).

Technical version

  1. R-CNN (Girshick et al., 2014): about 2,000 selective-search proposals, each warped and passed through a CNN, then SVMs classify and a regressor refines the box. Very slow.
  2. Fast R-CNN (2015): run the CNN once per image; RoI pooling cuts a fixed-size feature for each proposal; one network outputs softmax class and box offsets with a multi-task loss.
  3. Faster R-CNN (2015): a Region Proposal Network slides over the feature map with anchors (3 scales × 3 aspect ratios) and predicts objectness and box offsets, replacing selective search.
  4. YOLO: S×S grid, each cell predicts B boxes (x, y, w, h, confidence) and C class probabilities: S = 7, B = 2, C = 20 gives a 7×7×30 output. SSD predicts from several feature-map scales.
  5. NMS: sort by score, keep the top box, remove boxes with IoU above a threshold (say 0.5) with it, repeat. Metric: mean average precision (mAP) at IoU 0.5.

5Key formulas

\[\text{IoU}=\frac{\text{area}(B_p\cap B_g)}{\text{area}(B_p\cup B_g)}=\frac{I}{A_p+A_g-I}\] \[I=\max\bigl(0,\ \min(x_2,x_2')-\max(x_1,x_1')\bigr)\times\max\bigl(0,\ \min(y_2,y_2')-\max(y_1,y_1')\bigr)\] \[\textbf{Multi-task loss:}\quad L=L_{\text{cls}}(p,u)+\lambda\,[u\ge1]\,L_{\text{box}}(t,v)\qquad\qquad \textbf{YOLO output}=S\times S\times(B\cdot5+C)\]
SymbolMeaning
\(B_p,\ B_g\)Predicted box and ground-truth box.
\((x_1,y_1),(x_2,y_2)\)Top-left and bottom-right corners.
\(L_{\text{cls}},\ L_{\text{box}}\)Classification loss (cross-entropy) and box regression loss (smooth L1).
\(u\ge1\)Box loss is used only for real objects, not background.
\(S,B,C\)Grid size, boxes per cell, number of classes.

6Worked example

Ground truth (40, 40)–(120, 120); prediction (60, 50)–(140, 130). Compute IoU. Then apply NMS (IoU threshold 0.5) to three "dog" boxes: P (score 0.9), Q (0.8, IoU with P = 0.7), R (0.6, IoU with P = 0.1, with Q = 0.2). Finally count YOLO outputs.

  1. Areas: ground truth 80 × 80 = 6400; prediction 80 × 80 = 6400.
  2. Overlap width = min(120, 140) − max(40, 60) = 60; height = min(120, 130) − max(40, 50) = 70; I = 4200.
  3. Union = 6400 + 6400 − 4200 = 8600. IoU = 4200/8600 = 0.488. Below 0.5, so this counts as a miss.
  4. NMS: keep P (highest). Q overlaps P with 0.7 > 0.5, remove Q. R overlaps P with only 0.1, keep R.
  5. YOLO with S = 7, B = 2, C = 20: 7 × 7 × (2 × 5 + 20) = 7 × 7 × 30 = 1,470 numbers per image.

Answer: IoU = 0.488 (just short of a match); NMS keeps P and R; YOLO output has 1,470 values.

7Advantages, disadvantages, applications

Advantages

  • Finds many objects of many classes in one image.
  • One-stage detectors run in real time.
  • Backbones transfer from ImageNet.

Disadvantages

  • Needs box-labelled data.
  • Small and crowded objects are hard.
  • Trade-off between speed and accuracy.

Applications

  • Pedestrian and vehicle detection in self-driving.
  • Face detection, CCTV analytics.
  • Retail shelf monitoring, medical lesion detection.

9Exam corner

2 marksWhat is IoU? Why is it used in object detection?

IoU is the area of overlap between the predicted and true boxes divided by the area of their union. It measures localization quality; a detection is usually counted correct when IoU ≥ 0.5, and IoU is also used inside NMS.

2 marksWhat is non-maximum suppression?

A post-processing step that removes duplicate detections: keep the highest-scoring box, discard other boxes of the same class whose IoU with it exceeds a threshold, and repeat for the remaining boxes.

2 marksWhat is the role of the RPN in Faster R-CNN?

The Region Proposal Network slides over the shared feature map and, at each position, scores several anchor boxes for "object or not" and refines them, producing proposals far faster than selective search.

Automatic Image Captioning

1One-line definition

Automatic image captioning generates a natural-language sentence describing an image, using a CNN encoder to turn the image into a feature vector and an LSTM decoder to generate the sentence word by word from it.

2Pipeline diagram to draw: CNN encoder → LSTM decoder

3Interactive demo: decoding a caption word by word

4Step-by-step explanation

In simple words

  1. A CNN already trained on ImageNet "looks" at the photo and summarises it as a list of numbers.
  2. That summary is handed to an LSTM, which is a language model.
  3. The LSTM writes one word, then uses that word to decide the next one, until it writes "end".
  4. It learns from thousands of images, each with human-written captions.

Technical version

  1. Encoder: a pretrained CNN (Inception, ResNet) with the classifier removed gives a vector; a linear layer maps it to the word-embedding size. It is fed as \(x_{-1}\) (Show and Tell) or used to initialise \(h_0, c_0\).
  2. Decoder: \(x_t=W_e S_t\) (word embedding), \(h_t=\text{LSTM}(x_t,h_{t-1})\), \(p_{t+1}=\text{softmax}(W_o h_t)\).
  3. Training: maximise \(\log p(S\mid I)\) with teacher forcing (feed the true previous word).
  4. Inference: greedy or beam search (Topic 11).
  5. With attention ("Show, Attend and Tell", Xu et al., 2015) the decoder looks at different image regions for each word (Topic 6).
  6. Datasets: Flickr8k, Flickr30k, MS-COCO (5 captions per image). Metrics: BLEU, METEOR, CIDEr.

5Key formulas

\[x_{-1}=\text{CNN}(I),\qquad x_t=W_eS_t,\qquad h_t=\text{LSTM}(x_t,h_{t-1}),\qquad p_{t+1}=\text{softmax}(W_oh_t)\] \[\log p(S\mid I)=\sum_{t=0}^{N}\log p(S_t\mid I,S_0,\dots,S_{t-1})\qquad\qquad L=-\sum_{t}\log p_t(S_t)\] \[\textbf{BLEU-n precision}=\frac{\text{matching n-grams (clipped)}}{\text{n-grams in candidate}}\]
SymbolMeaning
\(I\)The input image.
\(S_t\)The t-th word of the caption (one-hot).
\(W_e\)Word-embedding matrix.
\(W_o\)Output layer mapping the hidden state to vocabulary scores.
\(p_t\)Probability distribution over words at step t.

6Worked example

The decoder generates "a dog runs <end>" with chosen-word probabilities 0.6, 0.5, 0.4, 0.7. Find the caption probability and the loss. Then compute BLEU-1 precision of the candidate "a dog runs on grass" against the reference "a dog is running on the grass".

  1. Caption probability = 0.6 × 0.5 × 0.4 × 0.7 = 0.084.
  2. Loss = −ln 0.084 = 2.477; term by term 0.511 + 0.693 + 0.916 + 0.357 = 2.477.
  3. BLEU-1: candidate words a, dog, runs, on, grass (5 words).
  4. Found in the reference: a, dog, on, grass = 4 ("runs" is not "running").
  5. Unigram precision = 4/5 = 0.8.

Answer: p = 0.084, loss = 2.477; BLEU-1 precision = 0.8.

7Advantages, disadvantages, applications

Advantages

  • Trained end to end; no hand-written templates.
  • Reuses strong pretrained CNNs.
  • Produces fluent, varied sentences.

Disadvantages

  • Can mention objects that are not there (hallucination).
  • Tends towards generic captions.
  • Automatic metrics agree only partly with humans.

Applications

  • Describing images to visually impaired users.
  • Image search and indexing.
  • Automatic alt-text on social media.

9Exam corner

2 marksWhat is the role of the CNN and the LSTM in image captioning?

The CNN is the encoder: it converts the image into a fixed-length feature vector. The LSTM is the decoder: a language model that, conditioned on that vector, generates the caption one word at a time.

2 marksWhat is teacher forcing?

During training the decoder receives the true previous word from the reference caption as its next input, instead of its own prediction. This speeds up and stabilises training.

2 marksName two evaluation metrics for captioning.

BLEU (n-gram precision against reference captions) and CIDEr (consensus-based, weights n-grams by TF-IDF). METEOR and ROUGE are also used.

Image Generation with GANs

1One-line definition

GAN-based image generation trains a generator network that turns a random latent vector z into a realistic image, by competing against a discriminator that tries to tell generated images from real ones; DCGAN made this work with convolutional networks.

2Pipeline diagram to draw: DCGAN generator and discriminator

3Interactive demo: walking through latent space

4Step-by-step explanation

In simple words

  1. Pick 100 random numbers: that is z, the "seed" of the image.
  2. The generator turns the seed into a small, deep block of numbers, then repeatedly doubles its size until it is a full image.
  3. The discriminator, a normal CNN, says how real the image looks.
  4. The generator learns from that verdict and improves; both train in turns (Unit II, Topic 7).
  5. After training, every new random seed gives a new image that never existed.

Technical version

  1. DCGAN rules: strided convolutions instead of pooling (D) and transposed convolutions (G); batch norm in both (not on G's output or D's input); ReLU in G with tanh output; LeakyReLU in D; no fully connected hidden layers.
  2. Latent arithmetic: averaged z vectors support "man with glasses − man + woman ≈ woman with glasses" (Radford et al.).
  3. Conditional GAN (Mirza and Osindero, 2014) gives G and D a label y, so you choose what to generate.
  4. Image-to-image: pix2pix (paired data, Isola et al., 2017); CycleGAN (unpaired, cycle-consistency loss, Zhu et al., 2017).
  5. High resolution: progressive growing and StyleGAN (Karras et al., 2019). Super-resolution: SRGAN.
  6. Evaluation: Inception Score (IS) and Fréchet Inception Distance (FID, lower is better).

5Key formulas

\[\min_G\max_D\ \mathbb E_{x\sim p_{\text{data}}}[\log D(x)]+\mathbb E_{z\sim p_z}[\log(1-D(G(z)))]\] \[\textbf{Conditional GAN:}\quad \min_G\max_D\ \mathbb E[\log D(x\mid y)]+\mathbb E[\log(1-D(G(z\mid y)\mid y))]\] \[\textbf{Cycle consistency:}\quad L_{\text{cyc}}=\mathbb E\lVert F(G(x))-x\rVert_1+\mathbb E\lVert G(F(y))-y\rVert_1\] \[\textbf{Transposed conv size:}\quad O=(W-1)S-2P+F\]
SymbolMeaning
\(z\)Latent noise vector, e.g. 100 numbers from N(0, 1).
\(G,\ D\)Generator and discriminator.
\(y\)Condition (class label, sketch, or other image).
\(G,\ F\) in CycleGANMappings X → Y and Y → X.
\(W,F,S,P\)Input size, filter size, stride, padding.

6Worked example

Check the DCGAN generator sizes. z has 100 numbers and is projected to 4×4×1024. Each transposed conv uses F = 4, S = 2, P = 1.

  1. Projection weights: 100 × (4 × 4 × 1024) = 100 × 16,384 = 1,638,400.
  2. Layer 1: O = (4 − 1) × 2 − 2 × 1 + 4 = 8, giving 8×8×512.
  3. Layer 2: (8 − 1) × 2 − 2 + 4 = 16, giving 16×16×256.
  4. Layer 3: (16 − 1) × 2 − 2 + 4 = 32, giving 32×32×128.
  5. Layer 4: (32 − 1) × 2 − 2 + 4 = 64, giving 64×64×3, with tanh so pixels lie in [−1, 1].

Answer: 4 → 8 → 16 → 32 → 64; each transposed conv with F = 4, S = 2, P = 1 exactly doubles the size.

7Advantages, disadvantages, applications

Advantages

  • Very sharp, realistic images.
  • Smooth, meaningful latent space.
  • Learns from unlabelled images.

Disadvantages

  • Unstable training; mode collapse.
  • Hard to evaluate.
  • Misuse: deepfakes and fake identities.

Applications

  • Face and art generation (StyleGAN).
  • Sketch-to-photo, day-to-night (pix2pix, CycleGAN).
  • Super-resolution, inpainting, data augmentation.

9Exam corner

2 marksList the architectural guidelines of DCGAN.

Replace pooling with strided convolutions (D) and transposed convolutions (G); use batch normalization in both; remove fully connected hidden layers; use ReLU in G (tanh at the output) and LeakyReLU in D.

2 marksWhat is a conditional GAN?

A GAN in which both generator and discriminator also receive extra information y, such as a class label, so the generator produces samples of the requested type: G(z | y).

2 marksWhat is the latent space of a GAN?

The space of input vectors z. A trained generator maps each point to an image; nearby points give similar images, and directions in the space can correspond to attributes such as pose or smile.

Video to Text with LSTM Models

1One-line definition

Video-to-text (video captioning) generates a sentence describing a video clip: a CNN extracts features from each frame, and an LSTM encoder–decoder reads the sequence of frame features and then writes the sentence word by word, as in the S2VT model.

2Pipeline diagram to draw: S2VT (sequence to sequence, video to text)

3Interactive demo: encoding frames, then decoding words

4Step-by-step explanation

In simple words

  1. A video is a sequence of images. Take, say, every 10th frame.
  2. A CNN turns each frame into a feature vector (what is visible).
  3. An LSTM reads these vectors in order, so it also learns what changes over time (actions).
  4. After the last frame, the same LSTM starts writing the sentence, one word at a time.
  5. It is like image captioning, but the encoder reads a sequence instead of a single image.

Technical version

  1. Mean-pool model (Venugopalan et al., NAACL 2015): average the CNN features of all frames into one vector and decode with an LSTM; loses temporal order.
  2. S2VT (Venugopalan et al., ICCV 2015): two stacked LSTMs. Encoding: layer 1 reads frame features; layer 2 receives <pad>. Decoding: layer 1 receives <pad>; layer 2 receives the previous word. Same weights in both stages.
  3. Inputs: RGB frame features (VGG fc7, 4096-d) and optionally optical-flow features for motion.
  4. Training: maximise \(\log p(y_1..y_m\mid x_1..x_n)\) with teacher forcing.
  5. Improvements: temporal attention over frames (Yao et al., 2015), 3-D CNN features (C3D, I3D), Transformers.
  6. Datasets: MSVD (YouTube2Text), MSR-VTT. Metrics: BLEU-4, METEOR, CIDEr.

5Key formulas

\[\textbf{Frame features:}\quad x_t=\text{CNN}(\text{frame}_t),\quad t=1,\dots,n\] \[\textbf{Encode:}\quad h_t=\text{LSTM}(x_t,h_{t-1})\qquad\qquad \textbf{Decode:}\quad h_{n+k}=\text{LSTM}(W_ey_{k-1},h_{n+k-1}),\quad p(y_k)=\text{softmax}(W_oh_{n+k})\] \[\textbf{Objective:}\quad \max_\theta\ \sum_{k=1}^{m}\log p(y_k\mid h_{n+k-1},y_{k-1};\theta)\qquad\qquad \textbf{Mean-pool:}\quad \bar x=\frac1n\sum_{t=1}^{n}x_t\]
SymbolMeaning
\(n,\ m\)Number of sampled frames and number of output words.
\(x_t\)CNN feature vector of frame t (e.g. 4096 numbers).

Attention Models for Computer Vision

1One-line definition

An attention model computes a set of weights over image regions that sum to 1 and uses their weighted average, so that at each step the network focuses on the most relevant parts of the image, for example the region matching the word being generated.

2Pipeline diagram to draw: soft attention in captioning

3Interactive demo: where the model looks for each word

4Step-by-step explanation

In simple words

  1. Squeezing a whole image into one vector forgets details.
  2. Instead, keep a grid of feature vectors, one per region.
  3. Before writing each word, the model gives every region a relevance score.
  4. Scores become weights (softmax), and the weighted average of the regions is what the model "sees" for this word.
  5. Bonus: the weights can be drawn as a heatmap, so we can check what the model looked at.

Technical version

  1. CNN feature map, e.g. VGG conv5: 14×14×512, giving L = 196 annotation vectors \(a_i\).
  2. Score: \(e_{ti}=f_{\text{att}}(a_i,h_{t-1})\), often \(w^\top\tanh(W_aa_i+W_hh_{t-1})\) (additive attention).
  3. Weights \(\alpha_{ti}=\text{softmax}_i(e_{ti})\); context \(z_t=\sum_i\alpha_{ti}a_i\) (soft, deterministic, trained by backprop).
  4. Hard attention samples one region from α; trained with REINFORCE (sampling).
  5. Other vision attention: channel attention (Squeeze-and-Excitation, Hu et al., 2018), spatial transformer networks, self-attention and Vision Transformers (ViT: image cut into 16×16 patches, Dosovitskiy et al., 2020).

5Key formulas

\[e_{ti}=w^\top\tanh\bigl(W_aa_i+W_hh_{t-1}\bigr)\qquad\qquad \alpha_{ti}=\frac{\exp(e_{ti})}{\sum_{k=1}^{L}\exp(e_{tk})}\qquad\qquad z_t=\sum_{i=1}^{L}\alpha_{ti}\,a_i\] \[\textbf{Self-attention (ViT):}\quad \text{Attention}(Q,K,V)=\text{softmax}\Bigl(\frac{QK^\top}{\sqrt{d_k}}\Bigr)V\] \[\textbf{Doubly stochastic regularisation:}\quad \lambda\sum_{i=1}^{L}\Bigl(1-\sum_t\alpha_{ti}\Bigr)^2\]
SymbolMeaning
\(a_i\)Feature vector of image region i.
\(L\)Number of regions (196).
\(h_{t-1}\)Decoder state before word t.
\(e_{ti},\ \alpha_{ti}\)Relevance score and attention weight of region i for word t; the α add to 1.
\(z_t\)Context vector given to the LSTM.
\(Q,K,V,\ d_k\)Queries, keys, values and key size in self-attention.

The last formula, from Show, Attend and Tell, encourages every region to receive some attention over the whole caption.

6Worked example

Three regions with scores \(e=(2,\ 1,\ 0)\) and feature vectors \(a_1=(1,0)\), \(a_2=(0,1)\), \(a_3=(1,1)\). Compute the attention weights and the context vector.

  1. Exponentials: \(e^2=7.389,\ e^1=2.718,\ e^0=1\); sum = 11.107.
  2. Weights: \(\alpha=(7.389,\ 2.718,\ 1)/11.107=(0.665,\ 0.245,\ 0.090)\); check: they add to 1.
  3. Context: \(z=0.665(1,0)+0.245(0,1)+0.090(1,1)\).
  4. \(z=(0.665+0.090,\ 0.245+0.090)=(0.755,\ 0.335)\).
  5. Region 1 dominates the context, as its score was highest.

Answer: α = (0.665, 0.245, 0.090); z = (0.755, 0.335).

Advantages

  • Uses fine image detail for each word.
  • Interpretable heatmaps.
  • Better results on long, detailed outputs.

Disadvantages

  • Extra computation per step.
  • Heatmaps do not always explain the decision faithfully.
  • Hard attention needs high-variance sampling-based training.

  • Image captioning and visual question answering.
  • Fine-grained classification (bird species).
  • Vision Transformers for classification and detection.

Case Study: Named Entity Recognition (NER)

1One-line definition

Named entity recognition finds names of people, organizations, locations and similar entities in text and labels each with its type; it is solved as sequence labelling, tagging every word with a scheme such as BIO.

2Pipeline diagram to draw: BiLSTM-CRF

3Interactive demo: entities and the BIO scheme

4Step-by-step explanation

In simple words

  1. Split the sentence into words.
  2. Turn each word into a vector; also look at its letters (a capital letter or "-pur" ending is a clue).
  3. A forward LSTM reads left to right and a backward LSTM reads right to left, so each word sees its whole context.
  4. For each word, score every possible tag.
  5. A CRF picks the best whole sequence of tags, refusing silly ones such as an I-ORG right after O.

Technical version

  1. Input: pretrained word embeddings (GloVe, word2vec) concatenated with a character-level BiLSTM or CNN embedding to handle unseen words and capitalisation.
  2. BiLSTM: \(h_t=[\overrightarrow{h_t};\overleftarrow{h_t}]\); a linear layer gives emission scores \(P_{t,y}\) for each tag.
  3. CRF: learns a transition matrix A; score of a tag sequence \(s(X,y)=\sum_t A_{y_{t-1},y_t}+\sum_t P_{t,y_t}\); normalise over all sequences.
  4. Training: maximise the log-probability of the correct tag sequence. Decoding: Viterbi algorithm.
  5. Evaluation: entity-level precision, recall and F1 (an entity counts only if both span and type are exact). Datasets: CoNLL-2003, OntoNotes 5.0.
  6. Today: fine-tuned Transformers (BERT) with a token classification head, often still with a CRF.

5Key formulas

\[h_t=\bigl[\overrightarrow{\text{LSTM}}(x_t,\overrightarrow{h}_{t-1});\ \overleftarrow{\text{LSTM}}(x_t,\overleftarrow{h}_{t+1})\bigr]\qquad P_t=W_ph_t+b_p\] \[s(X,y)=\sum_{t=0}^{n}A_{y_t,y_{t+1}}+\sum_{t=1}^{n}P_{t,y_t}\qquad\qquad p(y\mid X)=\frac{e^{s(X,y)}}{\sum_{\tilde y}e^{s(X,\tilde y)}}\] \[\text{Precision}=\frac{TP}{TP+FP}\qquad \text{Recall}=\frac{TP}{TP+FN}\qquad F_1=\frac{2PR}{P+R}\]
SymbolMeaning
\(x_t\)Embedding of word t (word + character parts).
\(h_t\)Concatenated forward and backward hidden states.
\(P_{t,y}\)Emission score: how much word t looks like tag y.
\(A_{i,j}\)Transition score from tag i to tag j (e.g. O → I-ORG gets a very low score).
\(TP,FP,FN\)Correct entities found, wrong entities found, true entities missed.

6Worked example

Part A: tag "Priya Sharma joined Infosys in Bengaluru" with BIO. Part B: on a test set with 10 true entities, a model predicts 8 entities, of which 6 are exactly right. Compute precision, recall and F1. Part C: a model without a CRF outputs O, I-ORG for "joined Infosys". Why does the CRF prevent this?

  1. Part A: Priya B-PER, Sharma I-PER, joined O, Infosys B-ORG, in O, Bengaluru B-LOC.
  2. Part B: precision = 6/8 = 0.75; recall = 6/10 = 0.60.
  3. F1 = 2 × 0.75 × 0.60/(0.75 + 0.60) = 0.90/1.35 = 0.667.
  4. Part C: in BIO an I-ORG must follow B-ORG or I-ORG. The CRF learns a very negative transition score for O → I-ORG, so Viterbi prefers O, B-ORG.

Answer: B-PER I-PER O B-ORG O B-LOC; P = 0.75, R = 0.60, F1 = 0.667; the CRF enforces valid tag transitions.

Advantages

  • No hand-crafted features or gazetteers needed.
  • Character features handle new names.
  • CRF gives consistent tag sequences.

Disadvantages

  • Needs token-level labelled data.
  • Ambiguity: "Jordan" may be a person or a country.
  • Nested entities ("Bank of India" inside a longer name) are hard for flat BIO.

Applications

  • Information extraction from news and documents.
  • Resume parsing; customer-support ticket routing.
  • Search engines, question answering, knowledge graphs.

Opinion Mining using RNNs

1One-line definition

Opinion mining (sentiment analysis) identifies the opinion or sentiment, positive, negative or neutral, expressed in text; an RNN reads the words in order, carries a hidden state that summarises the sentence, and classifies that final state.

2Pipeline diagram to draw: sentence → embeddings → RNN → sentiment

3Interactive demo: an RNN reading a review

4Step-by-step explanation

In simple words

  1. Each word becomes a vector in which similar words ("great", "excellent") sit close together.
  2. The RNN reads one word at a time and updates its memory.
  3. Because it reads in order, it can notice "not" before "good" or "but" before the real point.
  4. After the last word, the memory is passed to a classifier that outputs positive or negative.
  5. Plain RNNs forget long sentences, so LSTM or GRU cells are used in practice.

Technical version

  1. Levels: document, sentence, and aspect-based ("the food was great but the service was slow": food positive, service negative).
  2. Embedding: \(x_t=E[w_t]\), pretrained (word2vec, GloVe) or learned.
  3. Recurrence: \(h_t=\tanh(W_hh_{t-1}+W_xx_t+b)\); LSTM/GRU gates fix vanishing gradients.
  4. Output: \(\hat y=\text{softmax}(W_oh_T+b_o)\), or use max/mean pooling over all \(h_t\), or attention over them.
  5. Bidirectional LSTMs read both ways; aspect-based models add the aspect word as input or use attention to find opinion words for each aspect.
  6. Training: cross-entropy, backpropagation through time. Datasets: IMDB reviews, SST, Amazon and Yelp reviews, SemEval aspect data.

5Key formulas

\[x_t=E[w_t]\qquad h_t=\tanh\bigl(W_hh_{t-1}+W_xx_t+b\bigr)\qquad \hat y=\text{softmax}(W_oh_T+b_o)\] \[\textbf{Loss:}\quad L=-\sum_{k}y_k\log\hat y_k\qquad\qquad \textbf{Binary case:}\quad P(\text{positive})=\sigma(v^\top h_T+c)\]
SymbolMeaning
\(w_t,\ x_t\)t-th word and its embedding vector.
\(E\)Embedding matrix (vocabulary size × dimension).
\(h_t\)Hidden state after reading word t; \(h_T\) after the last word.
\(W_h,W_x,b\)Recurrent weights, input weights, bias, shared across time.
\(W_o,\ v\)Output layer weights.

6Worked example

A one-unit RNN with \(h_t=\tanh(0.5\,h_{t-1}+x_t)\), \(h_0=0\), and \(P(\text{positive})=\sigma(3h_T-0.5)\). The review "food was great" has scalar embeddings \(x=(0.2,\ 0,\ 1.5)\). Compute the prediction.

  1. \(h_1=\tanh(0.5\times0+0.2)=\tanh(0.2)=0.1974\).
  2. \(h_2=\tanh(0.5\times0.1974+0)=\tanh(0.0987)=0.0984\).
  3. \(h_3=\tanh(0.5\times0.0984+1.5)=\tanh(1.5492)=0.9137\).
  4. Score \(=3\times0.9137-0.5=2.241\); \(P=\sigma(2.241)=0.904\).

Answer: h = (0.197, 0.098, 0.914); P(positive) = 0.904, so the review is classified positive.

Advantages

  • Uses word order, so handles negation and contrast better than bag-of-words.
  • Works for any sentence length.
  • Embeddings generalise to synonyms.

Disadvantages

  • Sarcasm and irony are hard.
  • Plain RNNs forget long reviews (vanishing gradient).
  • Sequential, so slower to train than CNNs or Transformers.

Applications

  • Product and movie review analysis.
  • Brand monitoring on social media.
  • Customer feedback and survey analysis; market prediction.

Parsing and Sentiment Analysis using Recursive Neural Networks

1One-line definition

A recursive neural network applies the same composition function at every node of a tree, combining two child vectors into a parent vector bottom-up along the sentence's parse tree; a score on each parent can choose the parse, and a classifier on each node predicts the sentiment of that phrase.

2Pipeline diagram to draw: tree composition

3Interactive demo: sentiment flowing up the tree

4Step-by-step explanation

In simple words

  1. Language has structure: words form phrases, phrases form sentences.
  2. A recursive network follows that structure. It takes two neighbouring pieces and fuses them into one vector for the bigger phrase.
  3. The same fusing rule is used everywhere in the tree, from small phrases up to the whole sentence.
  4. Parsing: to find the tree, try fusing every neighbouring pair, keep the pair with the highest score, and repeat.
  5. Sentiment: put a small classifier on every node, so each phrase gets its own sentiment.

Technical version

  1. Composition: \(p=f(W[c_1;c_2]+b)\), with \(W\in\mathbb R^{d\times2d}\) shared by all nodes and f = tanh.
  2. Parsing (Socher et al., 2011): score \(s=u^\top p\); greedy bottom-up merging, or CKY-style search; trained with a max-margin objective so the correct tree scores higher than others. Also used for parsing natural scenes (image segments).
  3. Sentiment: \(y^{(n)}=\text{softmax}(W_sp^{(n)})\) at every node; the Stanford Sentiment Treebank has 11,855 sentences with 215,154 labelled phrases on 5 classes.
  4. RNTN (Socher et al., 2013) adds a tensor term: \(p=f([c_1;c_2]^\top V[c_1;c_2]+W[c_1;c_2])\), letting children interact multiplicatively, which handles negation better.
  5. Training: backpropagation through structure (BPTS). Tree-LSTM (Tai et al., 2015) puts LSTM cells on tree nodes.

5Key formulas

\[p=\tanh\Bigl(W\begin{bmatrix}c_1\\c_2\end{bmatrix}+b\Bigr)\qquad\qquad y=\text{softmax}(W_sp)\qquad\qquad s=u^\top p\] \[\textbf{RNTN:}\quad p=\tanh\Bigl(\begin{bmatrix}c_1\\c_2\end{bmatrix}^{\!\top}V^{[1:d]}\begin{bmatrix}c_1\\c_2\end{bmatrix}+W\begin{bmatrix}c_1\\c_2\end{bmatrix}\Bigr)\] \[\textbf{Tree score:}\quad s(T)=\sum_{n\in T}s(n)\qquad\qquad \textbf{Loss:}\quad L=-\sum_{\text{nodes } n}\sum_kt_k^{(n)}\log y_k^{(n)}\]
SymbolMeaning
\(c_1,c_2\)Vectors of the left and right children (d numbers each).
\(p\)Parent (phrase) vector, also d numbers.
\(W,b\)Composition weights (d × 2d) and bias, shared by all nodes.
\(W_s\)Sentiment classifier weights.
\(u\)Scoring vector for parsing.
\(V\)Tensor of d slices (RNTN).
\(t^{(n)}\)True sentiment label at node n.

6Worked example

Compose "not" \(c_1=(-1,\ 0.5)\) and "good" \(c_2=(0.8,\ 0.6)\) with \(W=\begin{bmatrix}0.5&-0.3&0.4&0.2\\-0.6&0.1&0.3&0.7\end{bmatrix}\), \(b=(0,\ 0.1)\). Then classify with \(W_s=\begin{bmatrix}-1.2&0.8\\1.2&-0.8\end{bmatrix}\) (rows: negative, positive), and score with \(u=(0.9,\ -0.4)\).

  1. Stack: \([c_1;c_2]=(-1,\ 0.5,\ 0.8,\ 0.6)\).
  2. Row 1: \(0.5(-1)-0.3(0.5)+0.4(0.8)+0.2(0.6)+0=-0.5-0.15+0.32+0.12=-0.21\).
  3. Row 2: \(-0.6(-1)+0.1(0.5)+0.3(0.8)+0.7(0.6)+0.1=0.6+0.05+0.24+0.42+0.1=1.41\).
  4. \(p=\tanh(-0.21,\ 1.41)=(-0.207,\ 0.887)\).
  5. Sentiment scores \(W_sp=(-1.2(-0.207)+0.8(0.887),\ \ldots)=(0.958,\ -0.958)\); softmax gives \(P(\text{neg})=0.872\), \(P(\text{pos})=0.128\).
  6. Parse score \(s=u^\top p=0.9(-0.207)-0.4(0.887)=-0.541\), compared with the scores of other candidate pairs to decide which to merge first.

Answer: p = (−0.207, 0.887); "not good" is negative with probability 0.872; parse score −0.541.

Advantages

  • Follows linguistic structure; handles negation and contrast at the right level.
  • Gives a sentiment for every phrase, not just the sentence.
  • One network does both parsing and phrase representation.

Disadvantages

  • Needs a parse tree (a parser or treebank).
  • Tree shapes differ, so batching on GPUs is hard; slow.
  • Phrase-level labels are costly.

Applications

  • Fine-grained sentiment analysis.
  • Syntactic parsing.
  • Paraphrase detection; scene parsing in images.

Sentence Classification using CNNs

1One-line definition

A sentence-classification CNN (Kim, 2014) stacks the word vectors of a sentence into a matrix, slides filters that each cover 3, 4 or 5 whole words down it to detect n-gram features, keeps the maximum of each feature map (max-over-time pooling), and classifies the result with a softmax layer.

2Pipeline diagram to draw: the Kim CNN

3Interactive demo: sliding 3-, 4- and 5-word filters

4Step-by-step explanation

In simple words

  1. Replace each word by its vector and stack them: the sentence becomes an image with one row per word.
  2. A filter looks at 3 (or 4, or 5) neighbouring words at once, like reading short phrases such as "not very good".
  3. Slide it down the sentence and keep the strongest match.
  4. Use many filters of each size; their strongest matches form one vector.
  5. A softmax layer turns that vector into a class: positive, negative, question type, and so on.

Technical version

  1. Input: \(x_{1:n}=x_1\oplus x_2\oplus\dots\oplus x_n\), with \(x_i\in\mathbb R^k\) (k = 300, word2vec).
  2. Convolution: filter \(w\in\mathbb R^{hk}\); \(c_i=f(w\cdot x_{i:i+h-1}+b)\), f = ReLU, giving \(c\in\mathbb R^{n-h+1}\).
  3. Max-over-time pooling: \(\hat c=\max(c)\); handles variable sentence length.
  4. Hyperparameters: windows 3, 4, 5 with 100 maps each → 300 features; dropout 0.5; L2 norm constraint 3 on weights; mini-batch 50.
  5. Variants: CNN-rand (random embeddings), CNN-static (fixed word2vec), CNN-non-static (fine-tuned), CNN-multichannel (one static and one tuned channel).
  6. Benchmarks: MR, SST-1, SST-2, Subj, TREC, CR, MPQA.

5Key formulas

\[c_i=\text{ReLU}\bigl(w\cdot x_{i:i+h-1}+b\bigr),\qquad i=1,\dots,n-h+1\qquad\qquad \hat c=\max_i c_i\] \[z=[\hat c_1,\dots,\hat c_m]\qquad\qquad y=\text{softmax}\bigl(W(z\circ r)+b\bigr),\quad r\sim\text{Bernoulli}(p)\] \[\textbf{Conv parameters per window size h:}\quad (h\cdot k)\cdot F+F\]
SymbolMeaning
\(n,\ k\)Number of words; embedding size.
\(h\)Filter height (window of h words).
\(x_{i:i+h-1}\)The h word vectors starting at word i, joined together.
\(c,\ \hat c\)Feature map and its maximum.
\(m,\ F\)Total number of filters (300); filters per window size (100).

6Worked example

Kim's setting: k = 300, windows 3, 4, 5 with 100 filters each, 2 classes. A sentence has n = 8 words. Find the feature-map lengths, the pooled vector size and the parameter counts.

  1. Feature-map lengths: 8 − 3 + 1 = 6, 8 − 4 + 1 = 5, 8 − 5 + 1 = 4.
  2. After max pooling each filter gives 1 number: 100 + 100 + 100 = 300-d vector, whatever n is.
  3. Conv weights: (3 + 4 + 5) × 300 × 100 = 360,000; biases 300; total 360,300.
  4. Output layer: 300 × 2 + 2 = 602.
  5. Toy pooling: if one filter's map is (0, 1.2, 0.4, 2.7, 0.9, 0), then \(\hat c=2.7\), from the window starting at word 4.

Answer: maps of length 6, 5, 4; pooled vector 300-d; 360,300 conv parameters + 602 output parameters (embeddings not counted).

7Advantages, disadvantages, applications

Advantages

  • Simple: one conv layer, yet strong results.
  • Fast and parallel (no recurrence).
  • Detects key phrases regardless of position.

Disadvantages

  • Sees only local n-grams; misses long-range order.
  • Max pooling discards where the feature occurred.
  • Depends on good pretrained embeddings.

Applications

  • Sentiment classification.
  • Question type classification (TREC).
  • Spam, topic and intent detection.

9Exam corner

2 marksWhat is max-over-time pooling?

Taking the maximum value of each feature map over all positions in the sentence. It keeps the strongest occurrence of each n-gram feature and gives a fixed-size vector for sentences of any length.

2 marksWhy do text-CNN filters span the full embedding width?

Each row is one word, and the individual embedding dimensions have no spatial order, so a filter must read whole words. It therefore slides only along the word dimension and acts as an n-gram detector.

2 marksWhat is the multichannel variant of Kim's CNN?

It uses two copies of the word vectors as two input channels: one kept fixed (static) and one fine-tuned during training (non-static). Every filter is applied to both channels.

Dialogue Generation with LSTMs

1One-line definition

Neural dialogue generation treats a conversation turn as sequence-to-sequence translation: an LSTM encoder reads the user's message into a context vector, and an LSTM decoder generates the reply word by word, trained on large collections of real conversations.

2Pipeline diagram to draw: Seq2Seq encoder–decoder

3Interactive demo: greedy decoding vs beam search

4Step-by-step explanation

In simple words

  1. The encoder LSTM reads the user's message one word at a time.
  2. Its final memory is a summary of the message, the "thought vector".
  3. The decoder LSTM starts from that summary and a <GO> token and writes the reply one word at a time.
  4. Each word it writes is fed back in to choose the next word, until it writes <EOS>.
  5. It learns from millions of real message–reply pairs (movie subtitles, support chats).

Technical version

  1. Encoder: \(h_t=\text{LSTM}_{\text{enc}}(x_t,h_{t-1})\); the final \((h_T,c_T)\) initialise the decoder. Sutskever et al. found that reversing the input order helps.
  2. Decoder: \(s_k=\text{LSTM}_{\text{dec}}(y_{k-1},s_{k-1})\), \(p(y_k)=\text{softmax}(W_os_k)\).
  3. Training: maximise \(\log p(Y\mid X)\) with teacher forcing.
  4. Decoding: greedy, beam search, or sampling (top-k) for variety.
  5. Attention (Bahdanau et al., 2015) lets the decoder look back at all encoder states, removing the single-vector bottleneck for long messages.
  6. Known problems: generic replies ("I don't know"), inconsistent persona, no long-term memory of the conversation. Fixes: maximum mutual information objective (Li et al., 2016), persona embeddings, hierarchical encoders (HRED), and today Transformer models.

6Worked example

Using the toy model from the demo: P(I) = 0.5, P(Sure) = 0.4, P(No) = 0.1 at step 1; after "I": am 0.4, can 0.35, will 0.25; after "Sure": thing 0.9; after "I am": fine 0.5; after "I can": help 0.8; "Sure thing" then <EOS> 0.8; "I am fine" and "I can help" then <EOS> 0.9. Compare greedy and beam (k = 2).

  1. Greedy: I (0.5) → am (0.5 × 0.4 = 0.20) → fine (0.10) → <EOS> (0.09). Reply "I am fine", p = 0.09.
  2. Beam step 1: keep I (0.5) and Sure (0.4).
  3. Step 2 candidates: I am 0.20, I can 0.175, I will 0.125, Sure thing 0.36. Keep Sure thing (0.36) and I am (0.20).
  4. Step 3: Sure thing <EOS> = 0.36 × 0.8 = 0.288; I am fine = 0.10. Keep both.
  5. Step 4: I am fine <EOS> = 0.09. Best finished reply: "Sure thing" with 0.288.
  6. "I can help" would score 0.5 × 0.35 × 0.8 × 0.9 = 0.126: better than greedy, but pruned by k = 2 at step 2.

Answer: greedy gives "I am fine" (0.09); beam k = 2 gives "Sure thing" (0.288), more than three times as probable.

7Advantages, disadvantages, applications

Advantages

  • Learns from raw conversation data; no hand-written rules.
  • Handles messages and replies of any length.
  • Same architecture as translation and summarisation.

Disadvantages

  • Generic, safe replies.
  • Inconsistent facts and persona; no real understanding.
  • Single thought vector struggles with long inputs (attention needed).
  • Can learn rude or biased language from data.

Applications

  • Chatbots and customer-support assistants.
  • Smart reply suggestions in email.
  • Machine translation and summarisation (same model).

9Exam corner

2 marksWhat is a thought vector?

The final hidden (and cell) state of the encoder LSTM after reading the whole input message. It is a fixed-size summary of the input and is used to initialise the decoder.

2 marksWhat is beam search?

A decoding method that keeps the k most probable partial output sequences at each step, extends each with every possible next word, and again keeps the top k, until the sequences end. With k = 1 it is greedy decoding.

2 marksWhy do Seq2Seq chatbots give generic replies?

Maximum-likelihood training favours replies that are acceptable after many different messages, such as "I don't know". Objectives such as maximum mutual information, diverse beam search and sampling reduce this.
