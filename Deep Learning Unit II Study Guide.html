A Probabilistic Theory of Deep Learning

1One-line definition

The probabilistic view treats a neural network as a model of a probability distribution \(p(y\mid\mathbf{x};\theta)\), so that training is maximum likelihood (or MAP) estimation: the loss function is the negative log-likelihood and the regularizer is the negative log-prior.

2Diagram to draw

3Interactive demo: likelihood and MSE have the same minimum

4Step-by-step explanation

In simple words

  1. Instead of saying "the answer is 5", a probabilistic network says "the answer is probably around 5".
  2. Training asks: which weights make the real training answers look most likely? This is maximum likelihood.
  3. Multiplying many small probabilities is awkward, so we take the log and flip the sign. The quantity to minimise is the negative log-likelihood, which is exactly the loss.
  4. If we also believe small weights are more likely before seeing data (a prior), we add that belief. This gives the regularizer.
  5. So the familiar recipe "loss + regularizer" is really "probability of data + probability of weights".

Technical version

  1. MLE: \(\theta^*=\arg\max_\theta\prod_i p(y_i\mid\mathbf{x}_i;\theta)=\arg\min_\theta\sum_i-\log p(y_i\mid\mathbf{x}_i;\theta)\), assuming the examples are independent and identically distributed (i.i.d.).
  2. Gaussian output \(y\sim\mathcal N(\hat y,\sigma^2)\): the NLL is \(\frac{1}{2\sigma^2}\sum(y_i-\hat y_i)^2\) plus a constant, so MLE = least squares (MSE).
  3. Bernoulli output (sigmoid) gives binary cross-entropy; categorical output (softmax) gives cross-entropy.
  4. MAP: by Bayes' rule \(p(\theta\mid D)\propto p(D\mid\theta)\,p(\theta)\). A Gaussian prior \(\mathcal N(0,\tau^2)\) adds an L2 penalty; a Laplace prior adds an L1 penalty.
  5. Fully Bayesian learning keeps the whole posterior and averages predictions over it. This gives uncertainty estimates; MC dropout (Gal and Ghahramani, 2016) approximates it cheaply.
  6. The 2015 paper "A Probabilistic Theory of Deep Learning" (Patel, Nguyen, Baraniuk) defines the Deep Rendering Model: an image is generated from a class, nuisance variables such as position and pose, and noise. Finding the most likely class by max-sum inference reproduces a CNN: template matching is convolution, a "render or not" switch gives ReLU, and maximising over small shifts gives max pooling.

5Key formulas

\[\textbf{Bayes' rule:}\quad p(\theta\mid D)=\frac{p(D\mid\theta)\,p(\theta)}{p(D)}\qquad \text{posterior}=\frac{\text{likelihood}\times\text{prior}}{\text{evidence}}\] \[\textbf{MLE:}\quad \theta_{\text{MLE}}=\arg\min_\theta\ -\sum_{i=1}^{N}\log p(y_i\mid\mathbf{x}_i;\theta)\] \[\textbf{MAP:}\quad \theta_{\text{MAP}}=\arg\min_\theta\ \Bigl[-\sum_{i=1}^{N}\log p(y_i\mid\mathbf{x}_i;\theta)\ -\ \log p(\theta)\Bigr]\] \[\textbf{Gaussian likelihood:}\quad -\log p(y\mid\mathbf{x})=\frac{(y-\hat y)^2}{2\sigma^2}+\tfrac12\log(2\pi\sigma^2)\] \[\textbf{Gaussian prior gives L2:}\quad -\log p(\theta)=\frac{\lVert\theta\rVert^2}{2\tau^2}+\text{const}\qquad\Rightarrow\qquad \lambda=\frac{\sigma^2}{\tau^2}\]

\(D\)The training data \(\{(\mathbf{x}_i,y_i)\}_{i=1}^N\).

6Worked example

Part A. A binary classifier outputs \(P(y=1)=0.9,\ 0.7,\ 0.2,\ 0.6\) for four examples whose true labels are \(1,\ 1,\ 0,\ 1\). Find the likelihood, the NLL and the average binary cross-entropy. Part B. A regression model predicts \(\hat y=(2.5,\ 2.5,\ 4.0)\) for targets \(y=(2,\ 3,\ 5)\) with \(\sigma=1\). Find the Gaussian NLL.

  1. Probability given to the true label: \(0.9,\ 0.7,\ 1-0.2=0.8,\ 0.6\).
  2. Likelihood \(=0.9\times0.7\times0.8\times0.6=0.3024\).
  3. NLL \(=-\ln0.3024=1.1960\). Term by term: \(0.1054+0.3567+0.2231+0.5108=1.1960\).
  4. Average binary cross-entropy \(=1.1960/4=0.2990\). The NLL and the cross-entropy are the same quantity.
  5. Part B: squared errors \(0.25,\ 0.25,\ 1.0\); sum \(=1.5\).
  6. NLL \(=\frac{N}{2}\ln(2\pi)+\frac{1}{2\sigma^2}\sum(y-\hat y)^2\) \(=1.5\times1.8379+0.75\) \(=2.7568+0.75=3.5068\).

Answer: likelihood 0.3024, NLL 1.1960, BCE 0.2990. Gaussian NLL 3.5068, of which only the 0.75 part depends on the weights (it is half the sum of squared errors).

7Advantages, disadvantages, applications

Advantages

  • Explains why each loss and regularizer is used.
  • Gives probabilities, so predictions come with confidence.
  • Bayesian versions estimate uncertainty.
  • Links deep networks to classical statistics and generative models.

Disadvantages

  • The assumed distribution may not match real noise.
  • Full Bayesian inference over millions of weights is intractable; only approximations are practical.
  • Softmax probabilities are often over-confident and need calibration.

Applications

  • Choosing the right loss for a new task.
  • Uncertainty in medical diagnosis and self-driving cars.
  • Generative models (VAE, GAN, diffusion).
  • Active learning: query the most uncertain examples.

9Exam corner

2 marksWhat is maximum likelihood estimation?

MLE chooses the parameters θ that make the observed training data most probable: \(\theta^*=\arg\max_\theta\prod_i p(y_i\mid\mathbf{x}_i;\theta)\). In practice the negative log-likelihood is minimised, and this is the network's loss function.

2 marksShow that minimising MSE is maximum likelihood.

If \(y=\hat y+\varepsilon\) with Gaussian noise \(\varepsilon\sim\mathcal N(0,\sigma^2)\), then \(-\log p(y\mid\mathbf{x})=\frac{(y-\hat y)^2}{2\sigma^2}+\text{const}\). Summing over examples, minimising the NLL is the same as minimising \(\sum(y-\hat y)^2\).

2 marksHow is L2 regularization related to a prior?

L2 regularization is MAP estimation with a zero-mean Gaussian prior on the weights. The negative log of \(\mathcal N(0,\tau^2)\) is \(\lVert\theta\rVert^2/2\tau^2\) plus a constant, which is an L2 penalty. A Laplace prior gives L1.

Backpropagation and Regularization

1One-line definition

Regularization is any change to the learning algorithm that aims to reduce the test (generalization) error, not the training error, for example a weight penalty, dropout or early stopping; with backpropagation, a penalty such as \(\tfrac{\lambda}{2}\lVert\mathbf{w}\rVert^2\) simply adds \(\lambda\mathbf{w}\) to each weight's gradient.

4Step-by-step explanation

In simple words

  1. Backpropagation finds how each weight affects the error; gradient descent then fixes the weights (Unit I).
  2. A big network can memorise the training set, including its noise. It then does badly on new data. This is overfitting.
  3. Regularization makes memorising harder. L2 says "keep weights small". L1 says "use as few weights as possible". Dropout says "do not depend on any single neuron". Early stopping says "stop before you start memorising".
  4. We watch a validation set that the model never trains on. Its error tells us whether we are overfitting.

Technical version

  1. Regularized objective: \(\tilde J(\mathbf{w})=J(\mathbf{w})+\lambda\,\Omega(\mathbf{w})\). Backprop computes \(\nabla J\) as usual and adds \(\lambda\nabla\Omega\).
  2. L2 (weight decay): \(\Omega=\tfrac12\lVert\mathbf{w}\rVert^2\). The update becomes \(\mathbf{w}\leftarrow(1-\eta\lambda)\mathbf{w}-\eta\nabla J\): every step first shrinks the weights by a constant factor.
  3. L1: \(\Omega=\lVert\mathbf{w}\rVert_1\) adds \(\lambda\,\operatorname{sign}(\mathbf{w})\): a constant pull towards zero that drives many weights exactly to zero (feature selection).
  4. Dropout (Srivastava et al., 2014): each hidden unit is kept with probability \(p\) during training. This trains an exponential number of thinned networks that share weights and approximates averaging them at test time.
  5. Early stopping: stop when validation error has not improved for a set number of epochs (the patience) and keep the best weights.
  6. Data augmentation (flips, crops, rotations) and noise injection enlarge the training distribution. Biases are usually not penalized.

5Key formulas

\[\textbf{L2:}\quad \tilde J=J+\frac{\lambda}{2}\lVert\mathbf{w}\rVert_2^2,\qquad \nabla\tilde J=\nabla J+\lambda\mathbf{w},\qquad \mathbf{w}\leftarrow(1-\eta\lambda)\,\mathbf{w}-\eta\nabla J\] \[\textbf{L1:}\quad \tilde J=J+\lambda\lVert\mathbf{w}\rVert_1=J+\lambda\sum_i|w_i|,\qquad \nabla\tilde J=\nabla J+\lambda\,\operatorname{sign}(\mathbf{w})\] \[\textbf{Dropout (inverted):}\quad r_j\sim\text{Bernoulli}(p),\qquad \tilde h_j=\frac{r_j\,h_j}{p}\quad\text{(training)},\qquad \tilde h_j=h_j\quad\text{(test)}\] \[\textbf{Bias–variance:}\quad \mathbb E\bigl[(y-\hat f)^2\bigr]=\text{Bias}^2+\text{Variance}+\text{irreducible noise}\]
SymbolMeaning
\(J,\ \tilde J\)Original cost and regularized cost.
\(\lambda\)Regularization strength. 0 means no regularization.
\(\eta\)Learning rate.
\(\lVert\mathbf{w}\rVert_2^2,\ \lVert\mathbf{w}\rVert_1\)Sum of squared weights; sum of absolute weights.
\(p\)Probability of keeping a unit (drop probability is \(1-p\)).
\(r_j\)Random mask: 1 means unit j is kept, 0 means dropped.

6Worked example

Weights \(\mathbf{w}=(0.8,\,-1.5)\), loss gradient from backprop \(\nabla J=(0.2,\,-0.4)\), \(\eta=0.1\), \(\lambda=0.5\). Do one update with no regularization, with L2 and with L1. Then apply inverted dropout (keep probability 0.5) to \(\mathbf{h}=(2.0,\,0.5,\,1.2,\,3.0)\) with mask \((1,0,1,0)\).

  1. No regularization: \(\mathbf{w}-\eta\nabla J=(0.8-0.02,\ -1.5+0.04)=(0.78,\,-1.46)\).
  2. L2 gradient: \(\nabla J+\lambda\mathbf{w}=(0.2+0.4,\ -0.4-0.75)=(0.6,\,-1.15)\).
  3. L2 update: \((0.8-0.06,\ -1.5+0.115)=(0.74,\,-1.385)\). Check with the decay form: \((1-0.05)(0.8,-1.5)-0.1(0.2,-0.4)=(0.74,\,-1.385)\).
  4. L1 gradient: \(\nabla J+\lambda\operatorname{sign}(\mathbf{w})=(0.2+0.5,\ -0.4-0.5)=(0.7,\,-0.9)\).
  5. L1 update: \((0.8-0.07,\ -1.5+0.09)=(0.73,\,-1.41)\).
  6. Dropout: keep units 1 and 3 and divide by 0.5: \(\tilde{\mathbf{h}}=(4.0,\ 0,\ 2.4,\ 0)\). On average each unit keeps its original expected value.

Answer: plain (0.78, −1.46); L2 (0.74, −1.385); L1 (0.73, −1.41); dropout output (4.0, 0, 2.4, 0). Both penalties pull the weights towards zero.

7Advantages, disadvantages, applications

Advantages

  • Better accuracy on unseen data.
  • L2 and dropout are one-line additions to backprop.
  • L1 gives sparse, smaller models.
  • Early stopping also saves training time.

Disadvantages

  • Extra hyperparameters (λ, dropout rate, patience) to tune.
  • Too much regularization causes underfitting.
  • Dropout slows convergence (more epochs needed).
  • L1 is not differentiable at 0.

Applications

  • Weight decay in almost every CNN and Transformer.
  • Dropout in fully connected layers (AlexNet used 0.5).
  • Augmentation in image classification.
  • L1 for feature selection and model compression.

9Exam corner

2 marksDifferentiate overfitting and underfitting.

Overfitting: the model fits the training data, including its noise, so training error is low but test error is high. Underfitting: the model is too simple to capture the pattern, so both training and test errors are high.

2 marksWhy does L1 regularization give sparse weights but L2 does not?

The L1 constraint region is a diamond with corners on the axes, and the loss contour usually first touches it at a corner, where some weights are exactly zero. Equivalently, L1 pulls with a constant force λ even near zero, while L2's pull λw fades as w gets small.

2 marksWhat is dropout? What happens at test time?

Dropout randomly removes each hidden unit with probability \(1-p\) at every training step, so units cannot co-adapt. At test time all units are used; activations are scaled so their expected value matches training (with inverted dropout this scaling is done during training).

Batch Normalization

1One-line definition

Batch normalization normalizes each feature of a layer's input over the current mini-batch to zero mean and unit variance, then applies a learnable scale \(\gamma\) and shift \(\beta\); it was introduced by Ioffe and Szegedy (2015) to make deep networks train faster and more stably.

2Diagram to draw

3Interactive demo: histograms before and after batch norm

4Step-by-step explanation

In simple words

  1. As the early layers learn, the numbers they pass to later layers keep changing in size and centre. The later layers keep chasing a moving target.
  2. Batch norm takes each feature in the current mini-batch, subtracts the average and divides by the spread. Now every layer receives numbers of a familiar size.
  3. Forcing everything to mean 0, spread 1 might be too strict, so two learnable knobs, γ and β, let the network rescale if it wants.
  4. At test time there may be only one image, so we use averages saved during training instead of batch statistics.

Technical version

  1. For a mini-batch \(B=\{x_1,\dots,x_m\}\) of one feature: compute \(\mu_B\), \(\sigma_B^2\), normalize, then \(y_i=\gamma\hat x_i+\beta\).
  2. Ioffe and Szegedy motivated BN by internal covariate shift: the change in the distribution of each layer's inputs during training. Later work (Santurkar et al., 2018) argued that its main benefit is a smoother loss landscape, which permits larger learning rates.
  3. Placement: usually after the linear or convolution layer and before the activation. The layer's bias becomes redundant because β takes its role.
  4. In CNNs statistics are computed per channel, over the batch and all spatial positions.
  5. Inference: running averages are kept during training, \(\mu_{\text{run}}\leftarrow m\,\mu_{\text{run}}+(1-m)\,\mu_B\) with momentum m, and are used in place of \(\mu_B,\sigma_B^2\).
  6. Gradients flow through \(\mu_B\) and \(\sigma_B^2\), so backpropagation is still exact. γ and β are learned like any weight. Each example's output depends slightly on the others in the batch, which adds noise and a small regularization effect.

5Key formulas

\[\mu_B=\frac1m\sum_{i=1}^{m}x_i\qquad\qquad \sigma_B^2=\frac1m\sum_{i=1}^{m}(x_i-\mu_B)^2\] \[\hat x_i=\frac{x_i-\mu_B}{\sqrt{\sigma_B^2+\varepsilon}}\qquad\qquad y_i=\gamma\,\hat x_i+\beta\equiv\text{BN}_{\gamma,\beta}(x_i)\] \[\textbf{Inference:}\quad y=\gamma\,\frac{x-\mu_{\text{run}}}{\sqrt{\sigma^2_{\text{run}}+\varepsilon}}+\beta\]
SymbolMeaning
\(m\)Mini-batch size (in the running-average formula, m is the momentum).
\(\mu_B,\ \sigma_B^2\)Mean and variance of the feature over the mini-batch.
\(\hat x_i\)Normalized value: mean 0, variance 1.
\(\varepsilon\)Small constant such as \(10^{-5}\) to avoid dividing by zero.
\(\gamma,\ \beta\)Learnable scale and shift, one pair per feature or channel.
\(\mu_{\text{run}},\ \sigma^2_{\text{run}}\)Running averages saved for inference.

6Worked example

A mini-batch of one feature has values \(x=(2,\ 4,\ 6,\ 8)\). Learned parameters are \(\gamma=2,\ \beta=1\). Take \(\varepsilon\approx0\). Find the BN output.

  1. Mean: \(\mu_B=(2+4+6+8)/4=5\).
  2. Variance: \(\sigma_B^2=\bigl((-3)^2+(-1)^2+1^2+3^2\bigr)/4=20/4=5\), so \(\sigma_B=\sqrt5=2.2361\).
  3. Normalize: \(\hat x=(-3,\,-1,\,1,\,3)/2.2361=(-1.3416,\,-0.4472,\,0.4472,\,1.3416)\). Check: mean 0, variance 1.
  4. Scale and shift: \(y=2\hat x+1=(-1.6833,\ 0.1056,\ 1.8944,\ 3.6833)\).
  5. The output has mean β = 1 and standard deviation γ = 2, whatever the input batch looked like.

Answer: y = (−1.6833, 0.1056, 1.8944, 3.6833), with mean 1 and standard deviation 2.

7Advantages, disadvantages, applications

Advantages

  • Allows much higher learning rates; faster training.
  • Less sensitive to weight initialization.
  • Keeps activations out of saturated regions, which eases vanishing gradients.
  • Mild regularization; can reduce the need for dropout.

Disadvantages

  • Depends on batch size; very small batches give noisy statistics.
  • Different behaviour in training and inference, a common source of bugs.
  • Awkward for RNNs and variable-length sequences.
  • Extra computation and memory.

Applications

  • Inception-v2, ResNet and most modern CNNs.
  • DCGAN generators and discriminators.
  • Training very deep networks from scratch.

9Exam corner

2 marksWhat is internal covariate shift?

It is the change in the distribution of a layer's inputs during training, caused by updates to the parameters of the earlier layers. Each layer must keep adapting to a moving input distribution, which slows training. Batch normalization was proposed to reduce it.

2 marksWhy are γ and β needed in batch normalization?

Forcing every input to mean 0 and variance 1 could limit what the layer can represent; for example a sigmoid would stay in its linear region. The learnable γ and β let the network restore any scale and shift, including the identity mapping.

2 marksHow does batch normalization work at test time?

At test time the mini-batch statistics are replaced by running averages of the mean and variance collected during training, so the output for an example does not depend on other test examples.

VC Dimension and Neural Networks

1One-line definition

The VC (Vapnik–Chervonenkis) dimension of a set of classifiers is the largest number of points that it can shatter, that is, separate correctly under every one of the \(2^n\) possible labellings; it measures the capacity of the model.

2Diagram to draw

3Interactive demo: can a line shatter these points?

4Step-by-step explanation

In simple words

  1. Put n points on paper. Colour them red or blue in every possible way: \(2^n\) colourings.
  2. If your model can separate every colouring correctly, it has shattered those points.
  3. The VC dimension is the biggest n for which you can find some points that get shattered.
  4. A higher VC dimension means a more powerful model, which can also memorise more easily, so it needs more data to generalize.
  5. Neural networks have very high VC dimension because they have many weights.

Technical version

  1. Hypothesis class H shatters a set S of n points if every one of the \(2^n\) labellings of S is produced by some \(h\in H\).
  2. \(d_{VC}(H)=\max\{n:\ \text{some set of } n \text{ points is shattered by } H\}\). "Some set", not every set: collinear points do not count against a line.
  3. Linear classifiers (perceptrons) in \(\mathbb R^d\) have \(d_{VC}=d+1\); in 2D that is 3.
  4. VC bound (Vapnik): with probability \(1-\delta\), test error ≤ training error + a term that grows with \(d_{VC}\) and shrinks with N. Finite VC dimension means the class is learnable (PAC learnable).
  5. Neural networks: for networks of threshold units with W weights, \(d_{VC}=O(W\log W)\) (Baum and Haussler, 1989). For ReLU networks with W weights and L layers, \(d_{VC}=O(WL\log W)\) (Bartlett et al., 2019).
  6. The puzzle: modern networks have far more weights than training examples and can even fit random labels (Zhang et al., 2017), yet they generalize well. VC bounds are too loose to explain this, so research looks at margins, weight norms and the implicit regularization of SGD.

6Worked example

Part A. Show that the VC dimension of a line in 2D is 3. Part B. A classifier with \(d_{VC}=10\) reaches 2% training error on \(N=10{,}000\) examples. Bound its test error with \(\delta=0.05\). Repeat for \(d_{VC}=100\).

  1. Part A, lower bound: three non-collinear points have \(2^3=8\) labellings. All + or all − need no boundary; each of the other 6 has one point alone, which a line cuts off. So 3 points are shattered.
  2. Part A, upper bound: for any 4 points, either one lies inside the triangle of the other three (label it differently from them) or they form a convex quadrilateral (use the XOR labelling of the diagonals). No line works in either case. So \(d_{VC}=3\).
  3. Part B: \(\ln\frac{2N}{d}=\ln2000=7.6009\), so \(d(\ln\frac{2N}{d}+1)=10\times8.6009=86.01\).
  4. \(-\ln\frac{\delta}{4}=-\ln0.0125=4.382\). Numerator \(=86.01+4.38=90.39\).
  5. Gap \(=\sqrt{90.39/10000}=\sqrt{0.009039}=0.0951\). Bound: \(0.02+0.0951=0.1151\).
  6. With \(d_{VC}=100\): \(\ln200=5.2983\), numerator \(=100\times6.2983+4.382=634.2\), gap \(=\sqrt{0.06342}=0.2518\).

Answer: d_VC = 3 for a line in 2D. Test error ≤ 11.5% when d_VC = 10, but the guarantee weakens to ≤ 27.2% when d_VC = 100 on the same data.

7Significance, limitations, applications

Significance

  • Gives a precise measure of model capacity.
  • Provides distribution-free bounds on test error.
  • Explains why bigger models need more data.
  • Foundation of statistical learning theory and SVM.

Limitations

  • Bounds are worst-case and very loose for deep networks.
  • Hard to compute exactly for complex models.
  • Ignores the data distribution and the training algorithm.
  • Does not explain why over-parameterized networks generalize.

Applications

  • Structural risk minimization: choosing model complexity.
  • Estimating how much data a model needs (a common rule of thumb is about 10 × d_VC examples).
  • Comparing the capacity of model families.

Deep vs Shallow Networks

1One-line definition

A shallow network has one hidden layer, while a deep network has two or more hidden layers that build a hierarchy of features; for many functions a deep network needs exponentially fewer units than a shallow one (depth efficiency).

2Diagram to draw

3Interactive demo: depth multiplies, width only adds

4Step-by-step explanation

In simple words

  1. Both kinds of network can in theory approximate any function (universal approximation, Unit I).
  2. But a shallow network builds the answer by adding many simple pieces side by side, so it may need a huge number of neurons.
  3. A deep network reuses what earlier layers found: edges become shapes, shapes become parts, parts become objects.
  4. Reusing features is far cheaper, like building with bricks that are themselves made of smaller bricks.
  5. Deep networks used to be hard to train. ReLU, good initialization, batch norm, residual connections, GPUs and big datasets fixed that after 2006 to 2015.

Technical version

  1. Shallow: \(f(\mathbf{x})=\sum_{i=1}^{n}v_i\,g(\mathbf{w}_i\cdot\mathbf{x}+b_i)\). Deep: \(f=f_L\circ f_{L-1}\circ\cdots\circ f_1\), a composition of layers.
  2. Depth efficiency: there are functions computable by a deep network of polynomial size that need exponentially many units in a shallow network (Telgarsky, 2016; also Eldan and Shamir, 2016).
  3. Linear regions: the number of linear pieces of a ReLU network can grow exponentially with depth but only polynomially with width (Montúfar et al., 2014).
  4. Hierarchical features: real data is compositional (pixels → edges → textures → parts → objects), which matches deep composition. Zeiler and Fergus (2014) visualised exactly this in CNN layers.
  5. Costs of depth: vanishing and exploding gradients, harder optimization, more hyperparameters, and the degradation problem that ResNet's skip connections solved.

5Key formulas

\[\textbf{Shallow:}\quad f(\mathbf{x})=\sum_{i=1}^{n}v_i\,g(\mathbf{w}_i\cdot\mathbf{x}+b_i)\qquad\qquad \textbf{Deep:}\quad f(\mathbf{x})=f_L\bigl(f_{L-1}(\cdots f_1(\mathbf{x}))\bigr)\] \[\textbf{Tent layer:}\quad t(x)=2\,\text{ReLU}(x)-4\,\text{ReLU}(x-0.5)\qquad t^{(k)}=\underbrace{t\circ t\circ\cdots\circ t}_{k\text{ times}}\ \text{has }2^{k}\text{ linear pieces}\] \[\textbf{Pieces of a one-hidden-layer ReLU net (1D input):}\quad \le n+1\] \[\textbf{Parameters of a fully connected net:}\quad \sum_{l=1}^{L}\bigl(n_{l-1}\,n_l+n_l\bigr)\]
SymbolMeaning
\(n\)Number of hidden neurons in the shallow network.
\(L\)Number of layers in the deep network.
\(f_l\)Function computed by layer l: \(f_l(\mathbf{h})=g(W_l\mathbf{h}+\mathbf{b}_l)\).
\(t(x)\)Tent map built from 2 ReLU units: rises from 0 to 1 then falls back to 0 on [0, 1].
\(n_l\)Number of units in layer l (\(n_0\) is the input size).

6Worked example

Part A. Count the parameters of a shallow MNIST classifier 784-1000-10 and a deep one 784-256-256-256-10. Part B. How many neurons do a deep and a shallow ReLU network need for the 5-fold sawtooth \(t^{(5)}\)?

  1. Shallow: \(784\times1000+1000=785{,}000\) and \(1000\times10+10=10{,}010\). Total \(=795{,}010\).
  2. Deep: \(784\times256+256=200{,}960\); two hidden-to-hidden layers \(2\times(256\times256+256)=131{,}584\); output \(256\times10+10=2{,}570\). Total \(=335{,}114\).
  3. The deep network has about 42% of the parameters and in practice reaches equal or better accuracy, because its layers reuse features.
  4. Part B: \(t^{(5)}\) has \(2^5=32\) linear pieces. Deep: 5 layers × 2 neurons = 10 neurons.
  5. Shallow: \(n+1\ge32\Rightarrow n\ge31\) neurons.

Answer: 795,010 vs 335,114 parameters; 10 deep neurons vs at least 31 shallow neurons, and the gap doubles with every extra fold.

7Advantages, disadvantages, applications

Deep: advantages

  • Learns hierarchical features automatically.
  • Exponentially more expressive per parameter.
  • State of the art in vision, speech and language.
  • Supports transfer learning (reuse the lower layers).

Deep: disadvantages

  • Vanishing or exploding gradients.
  • Needs large data and GPU compute.
  • Many hyperparameters; harder to interpret.
  • Prone to overfitting without regularization.

Where each fits

  • Shallow: small tabular data, simple functions, limited compute.
  • Deep: images (CNN), sequences (RNN, LSTM), text (Transformer), generation (GAN).

Convolutional Neural Networks (CNN)

1One-line definition

A convolutional neural network is a deep network for grid-like data such as images that uses convolution layers, small learnable filters slid across the input with shared weights, followed by non-linearity and pooling, and finally fully connected layers for classification.

2Diagram to draw

3Interactive demo: a filter sliding over an image

4Step-by-step explanation

In simple words

  1. An image is a grid of numbers. A filter is a tiny grid of weights, such as 3×3.
  2. Place the filter on the top-left corner, multiply overlapping numbers, add them up: that is one output number.
  3. Slide the filter across and down the whole image to get a feature map. Each filter detects one pattern, such as a vertical edge.
  4. ReLU keeps the positive responses. Pooling shrinks the map by keeping the strongest response in each small window.
  5. Many such layers detect more and more complex patterns. Finally fully connected layers decide the class.

Technical version

  1. Local receptive field: each output unit sees only a small F×F patch (across all input channels).
  2. Weight sharing: the same filter is used at every position, so the number of weights does not depend on image size, and the layer is translation equivariant.
  3. Hyperparameters: number of filters K, filter size F, stride S, zero padding P. Output size \((W-F+2P)/S+1\).
  4. Pooling (max or average, usually 2×2 stride 2) reduces size, adds small translation invariance and has no weights.
  5. Deep learning libraries actually compute cross-correlation (no kernel flip); since the filter is learned this makes no difference.
  6. History: LeCun et al. (1989) trained CNNs with backprop for digits; LeNet-5 (1998); AlexNet (2012) scaled it up on GPUs.

\(F\)Filter size.
\(P\)Zero padding added on each side.
\(S\)Stride: how many pixels the filter moves each step.
\(C_{\text{in}}\)Number of input channels (3 for an RGB image).

Generative Adversarial Networks (GAN)

1One-line definition

A generative adversarial network (Goodfellow et al., 2014) trains two networks against each other: a generator G that turns random noise into fake samples, and a discriminator D that tries to tell real samples from fake ones, until the fakes are indistinguishable from real data.

2Diagram to draw

3Interactive demo: watching a GAN train (1-D illustration)

4Step-by-step explanation

In simple words

  1. The generator is a counterfeiter making fake notes from random noise. The discriminator is the police checking notes.
  2. First the police study some real notes and some fakes, and get better at spotting fakes.
  3. Then the counterfeiter studies what gave the fakes away and improves them.
  4. They take turns. Each forces the other to get better.
  5. Training ends when the police can only guess (50% right), because the fakes look real. Then we keep the generator.

Technical version

  1. G maps noise \(\mathbf{z}\sim p_z\) to \(G(\mathbf{z})\), implicitly defining a distribution \(p_g\). D outputs \(D(\mathbf{x})\in[0,1]\).
  2. Two-player minimax game on the value function V(D, G): D maximises it, G minimises it.
  3. Algorithm (each iteration): sample m real examples and m noise vectors; update D by gradient ascent on V (k steps, often k = 1); sample m new noise vectors; update G by gradient descent on its loss.
  4. Optimal D for fixed G is \(D^*=p_{\text{data}}/(p_{\text{data}}+p_g)\). Substituting it, G minimises \(-\log4+2\,\text{JSD}(p_{\text{data}}\Vert p_g)\), whose global minimum is \(p_g=p_{\text{data}}\).
  5. Non-saturating loss: early on D easily rejects fakes and \(\log(1-D(G(z)))\) has tiny gradients, so in practice G maximises \(\log D(G(z))\) instead.
  6. Problems: mode collapse (G covers only a few modes), non-convergence or oscillation, vanishing gradients when D is too strong, no simple stopping criterion. Variants: DCGAN, conditional GAN, CycleGAN, WGAN, StyleGAN.

5Key formulas

\[\min_G\max_D\ V(D,G)=\mathbb E_{\mathbf{x}\sim p_{\text{data}}}\bigl[\log D(\mathbf{x})\bigr]+\mathbb E_{\mathbf{z}\sim p_z}\bigl[\log\bigl(1-D(G(\mathbf{z}))\bigr)\bigr]\] \[\textbf{Optimal discriminator:}\quad D^*(\mathbf{x})=\frac{p_{\text{data}}(\mathbf{x})}{p_{\text{data}}(\mathbf{x})+p_g(\mathbf{x})}\qquad\qquad C(G)=-\log4+2\,\text{JSD}\bigl(p_{\text{data}}\,\Vert\,p_g\bigr)\] \[\textbf{D loss:}\quad L_D=-\bigl[\log D(\mathbf{x})+\log\bigl(1-D(G(\mathbf{z}))\bigr)\bigr]\qquad\qquad \textbf{G loss (non-saturating):}\quad L_G=-\log D(G(\mathbf{z}))\]
SymbolMeaning
\(G,\ D\)Generator and discriminator networks.
\(\mathbf{z},\ p_z\)Random noise vector and its distribution (Gaussian or uniform).
\(p_{\text{data}},\ p_g\)Real data distribution and the generator's distribution.
\(D(\mathbf{x})\)Probability that x is real.
\(V(D,G)\)Value function of the game.
JSDJensen–Shannon divergence: 0 when the two distributions are identical.

6Worked example

On one real image D outputs \(D(\mathbf{x})=0.9\); on one fake image it outputs \(D(G(\mathbf{z}))=0.2\). Compute the discriminator loss, both versions of the generator loss, and the value of V at equilibrium.

  1. D loss \(=-[\ln0.9+\ln(1-0.2)]=-[-0.1054-0.2231]=0.3285\). Small, because D is doing well.
  2. Minimax G term: \(\ln(1-0.2)=\ln0.8=-0.2231\). Its gradient is weak when D(G(z)) is near 0.
  3. Non-saturating G loss: \(-\ln0.2=1.6094\). Large, so G gets a strong signal to improve.
  4. At equilibrium \(p_g=p_{\text{data}}\) and \(D=0.5\) everywhere: \(V=\ln0.5+\ln0.5=-\ln4=-1.3863\).

Answer: L_D = 0.3285; minimax G term = −0.2231; non-saturating L_G = 1.6094; equilibrium V = −log 4 = −1.3863 with D = 0.5.

Semi-supervised Learning

1One-line definition

Semi-supervised learning trains a model using a small amount of labelled data together with a large amount of unlabelled data, using the structure of the unlabelled data to improve on what the labelled data alone can teach.

2Diagram to draw

3Interactive demo: label propagation on two moons

4Step-by-step explanation

In simple words

  1. Labelling data is slow and costly (a doctor must label each X-ray), but unlabelled data is cheap and plentiful.
  2. Even without labels, unlabelled data shows where the clusters and gaps are.
  3. We assume points close together, or in the same cluster, share a label.
  4. So we spread the few known labels to their neighbours, or let the model label confident examples itself and retrain.
  5. Result: nearly the accuracy of full labelling at a fraction of the labelling cost.

Technical version

  1. Data: labelled set \(D_L=\{(\mathbf{x}_i,y_i)\}_{i=1}^{l}\) and unlabelled set \(D_U=\{\mathbf{x}_j\}_{j=l+1}^{l+u}\) with \(u\gg l\).
  2. Assumptions: smoothness (nearby points share labels), cluster (the decision boundary lies in low-density regions), manifold (data lies on a low-dimensional manifold).
  3. Self-training / pseudo-labelling: train on \(D_L\), predict \(D_U\), add predictions with confidence above a threshold τ as labels, retrain.
  4. Graph-based label propagation (Zhu and Ghahramani, 2002): build a similarity graph, propagate labels \(F\leftarrow D^{-1}WF\), clamp the labelled nodes, repeat until convergence.
  5. Consistency regularization: predictions should not change under noise or augmentation (Π-model, Mean Teacher, FixMatch). Loss \(L=L_{\text{sup}}+\lambda L_{\text{unsup}}\).
  6. Semi-supervised GAN (Salimans et al., 2016): the discriminator outputs K real classes plus a "fake" class, so unlabelled and generated data also train the classifier.

5Key formulas

\[\textbf{Combined loss:}\quad L=\underbrace{\frac1l\sum_{i=1}^{l}\ell\bigl(f(\mathbf{x}_i),y_i\bigr)}_{\text{supervised}}+\lambda\,\underbrace{\frac1u\sum_{j=1}^{u}\ell_u\bigl(f,\mathbf{x}_j\bigr)}_{\text{unsupervised}}\] \[\textbf{Graph weights:}\quad w_{ij}=\exp\Bigl(-\frac{\lVert\mathbf{x}_i-\mathbf{x}_j\rVert^2}{2\sigma^2}\Bigr)\qquad\qquad \textbf{Propagation:}\quad F\leftarrow D^{-1}WF,\ \ \text{then reset }F_L=Y_L\] \[\textbf{Pseudo-label:}\quad \hat y_j=\arg\max_k p(k\mid\mathbf{x}_j)\quad\text{used only if}\quad \max_k p(k\mid\mathbf{x}_j)\ge\tau\]
SymbolMeaning
\(l,\ u\)Number of labelled and unlabelled examples.
\(\ell_u\)Unsupervised loss, such as consistency or entropy.
\(\lambda\)Weight of the unsupervised term.
\(W,\ w_{ij}\)Similarity matrix and weight between points i and j.
\(D\)Diagonal degree matrix, \(D_{ii}=\sum_j w_{ij}\).
\(F,\ Y_L\)Current soft labels of all points; the true labels of the labelled points.
\(\tau\)Confidence threshold for pseudo-labels, such as 0.95.

6Worked example

Four points in a chain A – B – C – D with equal edge weights 1. A is labelled class 1 (score 1), D is labelled class 0 (score 0). B and C are unlabelled and start at 0.5. Run label propagation.

  1. Rule: each unlabelled node becomes the average of its neighbours; A and D stay fixed. So \(B\leftarrow(A+C)/2\) and \(C\leftarrow(B+D)/2\), using last round's values.
  2. Iteration 1: \(B=(1+0.5)/2=0.75\), \(C=(0.5+0)/2=0.25\).
  3. Iteration 2: \(B=(1+0.25)/2=0.625\), \(C=(0.75+0)/2=0.375\).
  4. Iteration 3: \(B=(1+0.375)/2=0.6875\), \(C=(0.625+0)/2=0.3125\).
  5. At convergence \(B=(1+C)/2\) and \(C=B/2\), so \(B=2/3=0.667\) and \(C=1/3=0.333\).
  6. Threshold at 0.5: B is class 1 (closer to A), C is class 0 (closer to D).

Answer: B → 0.667 (class 1), C → 0.333 (class 0). Each unlabelled node takes the label of the labelled node it is better connected to.

7Advantages, disadvantages, applications

Advantages

  • Cuts labelling cost greatly.
  • Uses abundant unlabelled data.
  • Often much more accurate than training on the few labels alone.
  • Works with any base model, including deep networks.

Disadvantages

  • Fails, and can even hurt accuracy, if its assumptions do not hold.
  • Wrong pseudo-labels can reinforce themselves (confirmation bias).
  • Graph methods scale poorly to millions of points.
  • Extra hyperparameters (λ, τ, σ, k).

Applications

  • Medical image diagnosis with few expert labels.
  • Speech recognition.
  • Web page and text classification.
  • Protein function prediction.

2 marksWhat is semi-supervised learning? Give an example.

Learning from a small labelled set plus a large unlabelled set. Example: classifying web pages when only a few hundred are labelled but millions of unlabelled pages are available.

2 marksState the assumptions of semi-supervised learning.

Smoothness: nearby points have the same label. Cluster: points in the same cluster share a label, so the boundary lies in a low-density gap. Manifold: high-dimensional data lies on a lower-dimensional manifold.

2 marksWhat is pseudo-labelling?

A model trained on labelled data predicts labels for unlabelled data; predictions above a confidence threshold are treated as true labels (pseudo-labels) and added to the training set, and the model is retrained.

1 · Probabilistic theory

  • Network models \(p(y\mid\mathbf{x};\theta)\).
  • MLE: minimise \(-\sum\log p\) = the loss.
  • Gaussian → MSE; Bernoulli → BCE; categorical → CE.
  • MAP: Gaussian prior → L2; Laplace prior → L1.
  • DRM (2015): CNN = inference in a generative model.

2 · Regularization

  • Reduce test error, not training error.
  • L2: \(\mathbf{w}\leftarrow(1-\eta\lambda)\mathbf{w}-\eta\nabla J\); circle.
  • L1: \(+\lambda\,\text{sign}(\mathbf{w})\); diamond → sparse.
  • Dropout: drop units at random; scale by 1/p.
  • Early stopping, augmentation, noise.

3 · Batch normalization

  • Mean, Variance, Normalize, Scale-shift.
  • \(\hat x=(x-\mu_B)/\sqrt{\sigma_B^2+\varepsilon}\), \(y=\gamma\hat x+\beta\).
  • Test time: running averages.
  • Higher learning rates, less init sensitivity.

4 · VC dimension

  • Largest set that can be shattered.
  • Line in 2D: 3 (XOR fails). Hyperplane in \(\mathbb R^d\): d + 1.
  • Test error ≤ train error + \(\sqrt{(d(\ln\frac{2N}{d}+1)-\ln\frac{\delta}{4})/N}\).
  • NN: grows with weights W and layers L.

5 · Deep vs shallow

  • Both universal; deep is exponentially more efficient.
  • Sawtooth: 2k deep neurons vs \(\ge2^k-1\) shallow.
  • Hierarchy: edges → parts → objects.
  • Depth needs ReLU, BN, init, skip connections.

6 · CNN

  • Conv → ReLU → Pool → … → Flatten → FC → Softmax.
  • Local receptive field + weight sharing.
  • Output \((W-F+2P)/S+1\).
  • Params \((F\cdot F\cdot C_{in}+1)\cdot K\).

7 · GAN

  • G makes fakes from noise; D says real or fake.
  • \(\min_G\max_D\ \mathbb E[\log D(x)]+\mathbb E[\log(1-D(G(z)))]\).
  • \(D^*=p_{data}/(p_{data}+p_g)\); equilibrium D = ½, V = −log 4.
  • Problems: mode collapse, instability.

8 · Semi-supervised

  • Few labelled + many unlabelled.
  • Assumptions: smoothness, cluster, manifold.
  • Methods: pseudo-labels, label propagation, consistency, SGAN.
  • \(L=L_{sup}+\lambda L_{unsup}\).
